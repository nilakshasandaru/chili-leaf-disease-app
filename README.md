\# Chili Leaf Disease Detection App



Mobile Application for Early and Late-Stage Classification of Chili Leaf Diseases Using Deep Learning



\*\*Team: Innovatex\*\* | Rajarata University of Sri Lanka



\## Project Structure



\- `backend/` — Flask REST API + MySQL (authentication, image upload, ML inference, treatment guidelines)

\- `mobile\_app/` — Flutter Android app for farmers

\- `admin\_dashboard/` — React admin panel for managing treatment guidelines

\- `ml\_training/` — Colab notebook and dataset preparation scripts

\- `docs/` — SRS and EC04 documentation



\## Tech Stack



\- \*\*Backend:\*\* Flask, SQLAlchemy, Flask-JWT-Extended, MySQL

\- \*\*Mobile:\*\* Flutter (Dart)

\- \*\*Admin:\*\* React, Vite, Bootstrap, Axios

\- \*\*ML:\*\* TensorFlow/Keras, MobileNetV2 transfer learning (9-class CNN, 90% test accuracy)
